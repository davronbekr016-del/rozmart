# Макеты

Кликабельные макеты на чистом HTML — открываются двойным щелчком, сервер
не нужен. Это не код приложения: данные в них вписаны руками, кнопки никуда
не отправляют.

| Файл | Что показывает | Статус |
|---|---|---|
| `index.html` | Витрина для покупателя | **Устарел.** Согласован с Директором 11.09.2026, но приложение ушло вперёд: появились нижнее меню, полный экран, поиск и профиль. Смотреть живое — `static/index.html` и адрес на Render |
| `staff.html` | Рабочее место сотрудника: приём заказа, сборка, курьер | Не построено. Это следующая крупная задача |
| `admin.html` | Админка: товары, цены, публикация, отчёты | Не построено |

Расхождение между `index.html` и живым приложением — не ошибка: макет
остался как след договорённости, по нему согласовывали состав экранов
и порядок шагов. Правду про сегодняшний вид показывает само приложение.

Требования, из которых выросли макеты, — в папке `Загрузки\Проект ROZMART`:
спецификация SRS, Регламент и схема процесса BPMN.
